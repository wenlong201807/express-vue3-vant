== 判读注意事项 ==
# 1) localhost 的「断网」= 服务不可达：包层面表现为 SYN→RST|ACK（连接拒绝，毫秒级）；真断网（远端域名拔网）是
#    SYN 发出后无应答、TCP 重传超时（秒级，无 RST），两者包特征不同，见 SOP「常见误读」
# 2) 服务端 store 为内存存储：重启 dev:server 清空旧数据，故本场景的「补齐」以 payload 数值差为证
#    （44.354 − 14.338 = 30.016），不能用服务端 GET /api/records 的前后对比（重启即归零）
# 3) frame 931/995/1025 为 guest 噪声心跳（user_id=guest），判读本会话时按 body 过滤
